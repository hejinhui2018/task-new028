# 织物组织设计台（Weave Studio）

面向小型织物工作室的多综织物组织设计工具。设计师在调整**穿综**、**提综**、**踏纹**的同时，即可看到自动计算出的**组织图**（布面交织结果），超限浮线在上机试织之前就被标出，并支持逐纬试织预演。

技术栈：**React 18 + TypeScript + Vite**，测试使用 **Vitest**，数据保存在浏览器 `localStorage`。

## 快速开始

```bash
npm install        # 安装依赖
npm run dev        # 开发服务器（默认 http://localhost:5173）
npm test           # 运行全部测试（vitest run）
npm run build      # 类型检查 + 生产构建（输出到 dist/）
npm run preview    # 预览生产构建
```

要求 Node.js ≥ 18。

## 功能

- **四区联动的设计台**（经典织物意匠布局）：
  - **穿综图**：行 = 综框（综 1 在最下，靠近组织图），列 = 经纱；点击格子把该经纱穿入对应综框。
  - **提综图**：综框 × 踏板连接矩阵；点击切换“踩下该踏板时该综框是否提升”。
  - **踏纹图**：行 = 纬纱（第 1 行在顶部），列 = 踏板；点击选择该行踩下的踏板。
  - **组织图**：由三者自动计算的交织矩阵，经组织点显经纱色、纬组织点显纬纱色，并画出循环边界。
- **完整关系重算**：任意格子修改后，沿 `穿综 + 提综 + 踏纹 → 组织图 → 循环展开 → 浮线检测` 全链路重新计算，试织预演同步更新。
- **参数设置**：经/纬纱颜色、横向/纵向循环次数（组织图按循环平铺展开）、允许的最大浮线长度。
- **浮线检测**：超过阈值的连续浮线在组织图中以红框 + 长度数字标出（选中为紫色），区分**经向/纬向**与**正面/背面**，并按循环连续处理（跨循环边界的浮线会被合并检出）；侧栏列表汇总所有问题。**点击问题条目或图中的浮线框，可定位到相关的穿综列（经向浮线）或踏纹行（纬向浮线）**，对应格子会紫色闪烁。
- **逐纬试织预演**：按踏纹顺序一行行生成布面，支持播放/暂停/步进/重置与速度调节，蓝框标出织口（最近织入的一行）。预演不缓存已织行——**编辑后从当前行继续播放也使用最新组织**。
- **本地保存与恢复**：每次修改自动写入浏览器本地存储，刷新后仍在；点击“恢复内置样稿”可随时回到内置破斜纹样稿。

## 内置样稿

破斜纹：**8 综、8 踏板、32 根经纱、24 行纬纱**。

- 穿综：破斜顺序 `1 3 5 7 2 4 6 8` 循环 4 次；
- 提综：4/4 斜纹，踏板 t 提升综框 t..t+3（mod 8）；
- 踏纹：顺踩 `1..8` 循环 3 次。

样稿经纬浮线最长均为 4，默认阈值 5 下无超限；把“最大浮线”调到 3 即可看到浮线标注与定位效果。

## 数据模型与计算公式

```ts
interface WeaveProject {
  threading: number[];     // threading[warp]  = 该经纱穿入的综框（0-based）
  tieUp: boolean[][];      // tieUp[harness][treadle] = 踩踏板时该综框是否提升
  treadling: number[];     // treadling[pick] = 该行纬纱踩下的踏板（0-based）
  // 以及：综框数、踏板数、经纬纱颜色、循环次数、最大浮线
}
```

组织图（`true` = 经组织点，即经纱在纬纱之上）：

```
drawdown[y][x] = tieUp[ threading[x] ][ treadling[y] ]
```

浮线定义：组织图某一**列**中的连续同值段 = 经向浮线（`true` 段在正面，`false` 段在背面）；某一**行**中的连续同值段 = 纬向浮线（`false` 段在正面，`true` 段在背面）。检测在循环展开后的组织图上进行，并把最外圈也视为循环相接（与实际布料的无限重复一致）。

试织预演的已织部分 = `drawdown.slice(0, pick)`，每次渲染都取自当前最新组织图，因此编辑后无需任何缓存失效处理。

## 项目结构

```
src/
  types.ts                 # WeaveProject 数据模型
  lib/
    weave.ts               # 组织矩阵计算、循环展开、经纬浮线检测（纯函数）
    preview.ts             # 逐纬试织预演状态机（纯函数）
    sample.ts              # 内置破斜纹样稿
    storage.ts             # localStorage 读写与数据校验
    *.test.ts              # 上述模块的测试
  state/
    project.ts             # 编辑动作 reducer（+ 测试）
  components/
    ThreadingGrid.tsx      # 穿综图
    TieUpGrid.tsx          # 提综图（综框 × 踏板矩阵）
    TreadlingGrid.tsx      # 踏纹图
    DrawdownCanvas.tsx     # 组织图（canvas，浮线标注与点击定位）
    PreviewPlayer.tsx      # 逐纬试织预演
    IssuesPanel.tsx        # 浮线问题列表
    SettingsPanel.tsx      # 颜色 / 循环 / 最大浮线设置
  App.tsx                  # 布局与状态编排
```

## 测试

`npm test` 运行 6 个测试文件、40 个用例，覆盖需求要求的四个方面及支撑模块：

- **组织矩阵计算**（`weave.test.ts`）：平纹棋盘格、关系式逐格验证，以及修改穿综/提综/踏纹后沿完整关系的重算；
- **循环展开**（`weave.test.ts`）：平铺尺寸与逐格内容、“先展开再算 ≡ 先算再展开”的等价性；
- **经纬浮线检测**（`floats.test.ts`）：经向/纬向、正面/背面、阈值边界、跨循环边界合并、整圈同值、跨边界拆分绘制；
- **编辑后的预演同步**（`preview.test.ts`）：逐行前进与自动停止、行数收缩钳制，以及编辑踏纹/穿综后从当前行继续必须使用最新组织；
- 另有本地存储往返与校验（`storage.test.ts`）、内置样稿规格（`sample.test.ts`）、编辑动作（`project.test.ts`）。
