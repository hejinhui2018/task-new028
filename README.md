# EventContract 埋点迁移验收台

业务埋点协议从 v1 升级到 v2 期间的联调验收工具，全部在浏览器本地运行（React + TypeScript + Vite，无后端）。

## 运行

```bash
npm install
npm run dev      # 开发
npm test         # 领域测试（vitest）
npm run build    # 类型检查 + 生产构建
```

## 它做什么

- **迁移契约维护**：v1→v2 事件映射、字段改名、字段拆分、兼容规则（缺失即记录，必填则失效）、隐私禁采字段、v2 必填字段，全部可在左侧面板维护；规则改动会立即按新契约重放全部已到达事件。
- **混合事件导入与旅程重放**：旧新 SDK 混合事件按到达顺序进入「隐私闸口 → 幂等去重 → 契约适配 → 旅程状态机」。
- **状态化结论**：每条事件给出 接受 / 等待 / 阻断 / 失效 / 重复 的结论与原因，并就地更新 会话关联、实验分组、转化归因 三份影响台账 —— 不是校验 JSON 后排序。
- **两条铁律**：旧版适配绝不伪造缺失信息（拆不出的字段留空并记 missing）；隐私事件在入闸处阻断，永不进入下游事件流。

## 操作

单步 / 自动播放 / 暂停 / 撤销 / 重做 / 重置；队列中可调整到达顺序（↑↓）、注入故障（重复投递、禁采字段、抹除会话、时间回拨）、移除事件；所有状态持久化到 localStorage，刷新后恢复。

## 内置场景

1. **基线**：新旧 SDK 混合有序到达 —— 全部接受，归因完整。
2. **字段改名缺失**：`exp` 未映射导致实验分组丢失；重新启用规则后结论即时翻转。
3. **重复与乱序**：开通事件晚到，发布重复投递 —— 乱序缓冲 + 幂等去重 + 自动补放。
4. **隐私阻断**：夹带 `email` 的事件被阻断，修复后重发恢复旅程。
5. **版本边界**：`plan_name` 拆不出 `billing_cycle`，兼容必填规则判失效；禁止伪造。
6. **旅程关联**：跨用户事件被接受但归因断裂。

## 测试

`src/domain/__tests__/` 覆盖：版本边界与不伪造、重复与乱序、旅程关联与失效、隐私阻断与下游纯净、重复重放确定性与撤销/重做等价。
